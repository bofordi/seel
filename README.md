# SellXBay — маркетплейс и скупка

Готовый стартовый проект: React + Vite + Supabase. В каталоге изначально **нет товаров**. Они появятся после добавления через админ-панель.

## Что уже заложено
- Публичный каталог без обязательной регистрации.
- Категории и поиск.
- Регистрация и вход.
- Анкета на скупку и создание чата.
- Чат поддержки и realtime-обновление сообщений.
- Заявка на открытие пользовательского магазина с модерацией.
- Админ-панель: публикация товаров, модерация заявок/магазинов, список чатов.
- Роли: admin, support_manager, buyback_manager, product_manager.
- Edge Function для безопасного создания менеджеров.
- Обязательное окно ознакомления с правилами при первом посещении браузера.

## Важно про первоначальный администратор
Пароль администратора **не зашит в исходники** и не хранится в браузере. Это сделано намеренно: пароль в клиентском коде может украсть любой посетитель сайта.

1. Создайте проект Supabase.
2. Откройте SQL Editor и выполните `supabase/schema.sql`.
3. В Authentication → Users создайте пользователя с email, который будет использоваться для входа администратора, и задайте ему пароль.
4. В SQL Editor выполните, подставив UUID созданного пользователя:
   ```sql
   update public.profiles set role='admin', display_name='BOFORD'
   where id='UUID_ПОЛЬЗОВАТЕЛЯ';
   ```
5. В корне проекта скопируйте `.env.example` в `.env` и заполните URL и anon key из Supabase → Project Settings → API. В `VITE_ADMIN_EMAIL` укажите email администратора. В форме входа можно вводить `BOFORD` как логин — приложение подставит этот email.
6. Установите Node.js LTS.
7. В терминале из папки проекта выполните:
   ```bash
   npm install
   npm run dev
   ```
   Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Создание менеджеров
Разверните Edge Function:
```bash
supabase functions deploy create-manager
```
Она использует service role key только на сервере Supabase. Не вставляйте service role key в `.env` с префиксом `VITE_`.

## Публикация в интернете
Проект можно развернуть на Vercel:
- импортируйте папку/репозиторий;
- добавьте `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_ADMIN_EMAIL` в Environment Variables;
- Build command: `npm run build`;
- Output directory: `dist`.

## Что нужно до реального запуска
- Настроить SMTP в Supabase для писем подтверждения/сброса пароля.
- Подключить платёжный провайдер и серверную обработку платежей: оплата пока не реализована.
- Добавить полноценный процесс оформления заказа/доставки и возвратов.
- Расширить админ-панель: назначение менеджеров по заявкам, фильтры, просмотр профилей и журнал действий.
- Проверить RLS-политики под выбранную бизнес-модель и пройти тестирование безопасности.
